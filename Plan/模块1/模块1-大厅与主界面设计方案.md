**文档版本**：v1.0  
**编写日期**：2026-07-10  
**所属模块**：模块1 - 前端多端交互与沉浸式界面模块  
**关联文档**：[outline.md](outline.md)

---

## 1. 方案概述

### 1.1 设计目标

为 AI跑团（多智能体叙事平台）打造一个具有**中世纪羊皮纸质感**的沉浸式大厅/主界面，实现"冒险者进入酒馆查看公告、翻阅好友名册、整理个人角色卡、浏览剧本架"的代入式体验。

### 1.2 核心设计理念

| 场景 | 风格 | 说明 |
|------|------|------|
| **大厅主界面** | 横向展开的破旧卷轴 | PC 端宽屏横向铺开的羊皮纸卷轴，左右两端为卷起的木棒，四个功能入口横向并排排列 |
| **房间内界面** | 酒馆沉浸式风格 | 加入房间后界面切换为酒馆沉浸式布局（后续方案设计） |

### 1.3 两个核心场景

- **场景1（大厅）**：羊皮纸主界面，是用户的操作总入口
- **场景2（房间内）**：酒馆风格界面，玩家真正开始游戏时的沉浸式环境

---

## 2. 技术选型

| 技术维度 | 选型 | 理由 |
|----------|------|------|
| **前端框架** | React 18 + TypeScript | 生态最丰富，适合大规模复杂交互 |
| **样式方案** | Tailwind CSS | 高度自定义，适合定制中世纪风格，无需依赖重型组件库 |
| **图标方案** | Lucide React + 自定义SVG | Lucide 提供基础图标，中世纪装饰性图标手工绘制 |
| **路由管理** | React Router v6 | 管理大厅 → 房间内部等不同场景的页面级路由 |
| **状态管理** | React Context + useReducer（模块1内部状态） | 大厅UI状态较简单，无需引入 Redux/Zustand。跨模块通信（如房间状态）通过模块2的事件总线进行 |
| **构建工具** | Vite | 快速开发体验，支持 TypeScript 和 Tailwind 开箱即用 |

### 3.2 羊皮纸卷轴视觉规范

#### 3.2.1 整体风格定位

**设计理念**：仿造中世纪破旧卷轴羊皮纸，历经岁月侵蚀，带有明显的使用痕迹、污渍、裂痕和边缘磨损，营造出从古老图书馆中翻出的失传手稿的质感。

#### 3.2.2 复古色彩调色板

采用**低饱和度、高明度差**的复古配色方案，模拟自然老化的色彩衰减：

| 色值 | 色彩名称 | 用途 | 备注 |
|------|---------|------|------|
| `#E8D5B7` | 陈旧羊皮纸底色 | 主要背景基调 | 泛黄的米色，带灰调 |
| `#C9A876` | 烘焙暗区 | 边缘阴影、折痕深处 | 模拟羊皮纸烤制痕迹 |
| `#B5936A` | 污渍色 | 水渍、油渍区域 | 不均匀分布 |
| `#4A3728` | 古墨色 | 标题文字、重要文字 | 褪色墨水感 |
| `#6B4423` | 铁锈褐 | 次级文字、日期标注 | 仿铁胆墨汁氧化色 |
| `#8B7355` | 封蜡红褐 | 强调元素、按钮高亮 | 模拟封蜡印记 |
| `#9A7B4F` | 黄铜金 | 装饰纹样、分隔线 | 做旧金属色 |
| `#2D1F17` | 焦炭黑 | 边框、烧焦边缘 | 最深色，用于破损区域 |
| `#3E2F23` | 烟熏灰褐 | 阴影、纹理叠加 | 半透明使用 |

#### 3.2.3 卷轴形态与边缘设计

**卷轴展开形态**：
- 顶部和底部保留**卷轴木棒**元素（深褐色圆柱，带木纹理）
- 羊皮纸从木棒处自然展开，边缘略带**卷曲阴影**
- 卷轴两端用**麻绳/丝带**装饰性固定（可选动态摆动效果）

**破损边缘处理**（重点强化）：
- 四边使用**不规则撕裂路径**，而非规则圆角
- 边缘处理层次：
  1. **基础撕裂**：SVG `clipPath` 定义随机锯齿状边缘
  2. **烧焦边**：深褐色到黑色渐变（`#2D1F17` → `#4A3728`），宽度 2-5px 不等
  3. **磨损透明区**：局部半透明处理，露出背景
  4. **边角卷曲**：右上角/左下角轻微卷起，投射阴影（`drop-shadow`）
- 边缘粗糙度：使用 SVG `feTurbulence` 的 `fractalNoise` 类型生成有机边缘

#### 3.2.4 纹理与做旧效果（多层叠加）

**第一层 - 羊皮纸基础纹理**：
- 使用 SVG `feTurbulence` 生成细腻纤维纹理
- 参数：`baseFrequency="0.02"`, `numOctaves="4"`
- 通过 `feColorMatrix` 调整为暖黄色调
- 不透明度：`opacity: 0.3`

**第二层 - 老化斑点与水渍**：
- 大面积不规则**褐色水渍**（`#B5936A`, 透明度 10-30%）
- 随机分布的**墨点**（`radial-gradient`，直径 5-20px）
- **发霉斑纹**（深褐色，`#6B4423`，使用 CSS `filter: blur(2px)` 模糊边缘）
- 位置：通过 `background-image` 叠加多个渐变，或使用绝对定位的装饰性 `<div>`

**第三层 - 折痕与裂纹**：
- 对角线/不规则**折痕**（深色线条，`#8B7355` 加阴影）
- 细小**裂纹网**（`1px` 深色线条，使用 SVG `<path>` 或 Canvas 绘制）
- 折痕处颜色加深，模拟纸张纤维断裂

**第四层 - 光影渲染**：
- 整体施加**微弱径向渐变**，中心稍亮，边缘渐暗（模拟古老纸张中心磨损较轻）
- 内阴影（`inset box-shadow`）：
  ```css
  box-shadow: 
    inset 0 0 120px rgba(45, 31, 23, 0.15),  /* 边缘暗角 */
    inset 0 0 50px rgba(201, 168, 118, 0.2); /* 中心暖光 */
  ```
- 卷轴木棒投射阴影到羊皮纸上（`0 5px 15px rgba(0,0,0,0.4)`）

**第五层 - 烧焦与破洞**：
- 右上角或左下角添加**小面积烧焦区域**（黑褐色不规则形状，半透明）
- 边缘局部**破洞**（使用 `mask-image` 或 SVG 镂空）
- 破洞边缘焦黑处理

#### 3.2.5 字体方案（强化复古感）

| 字体类型 | 推荐字体 | 备用方案 | 应用场景 |
|---------|---------|---------|---------|
| **标题字体** | `IM Fell DW Pica` | `Cinzel`, `UnifrakturMaguntia` | "冒险者大厅"等主标题 |
| **正文字体** | `Crimson Text` | `Lora`, `Merriweather` | 描述文字、卡片内容 |
| **装饰字体** | `MedievalSharp` | `Uncial Antiqua` | 首字母大写装饰 |
| **数字/数据** | `Cinzel Decorative` | `Spectral` | 人数、时间等数据 |

**字体渲染优化**：
- 使用 `text-shadow` 模拟墨水渗透效果：
  ```css
  text-shadow: 1px 1px 2px rgba(74, 55, 40, 0.3);
  ```
- 标题添加淡金色描边（可选）：
  ```css
  -webkit-text-stroke: 0.5px #9A7B4F;
  ```

#### 3.2.6 装饰性元素

**分隔线样式**：
- 使用手绘风格的装饰线（波浪线、绳结、藤蔓）
- SVG 路径绘制，带有不均匀粗细变化
- 颜色：`#8B7355` 或 `#6B4423`

**首字母装饰（Drop Cap）**：
- 每个面板标题首字母放大 2-3 倍
- 使用装饰性哥特字体
- 周围环绕简单花纹边框

**边角装饰**：
- 四角添加中世纪风格**装饰纹章**（SVG 图案）
- 图案风格：盾牌、剑、龙爪、藤蔓卷草
- 颜色：深褐色 + 黄铜金点缀

**封蜡印记**（可选）：
- 在重要按钮或标题旁添加圆形封蜡效果
- 使用径向渐变模拟蜡质光泽
- 中心压印纹章图案（略微凹陷感）

### 3.3 初始状态（默认首页）

用户进入大厅后看到的**默认界面**：

- PC 宽屏横向展开的破旧羊皮纸卷轴居中显示，左右两侧为深褐色木棒
- 卷轴顶部区域呈现欢迎标题（"冒险者大厅" / "欢迎回到酒馆"），衬线字体，配藤蔓装饰线
- 四个功能入口卡片**横向并排排列**，各自独占约 1/4 宽度，带标题、描述文字和进入按钮
- 入口卡片之间用中世纪风格竖向分隔线装饰（细藤蔓、细纵线）
- 背景为深色石墙/木板纹理，与明亮泛黄的羊皮纸形成强烈明暗对比

### 3.4 交互逻辑（单页 Tab 切换）

- **点击任意入口** → 羊皮纸内容区域从"横向四入口列表"切换为该功能的详细面板（横向布局保持不变）
- **切换后** → 卷轴顶部出现面包屑/返回按钮 + 当前功能标题，内容区全宽展开为详细面板
- **点击返回/面包屑** → 回到横向四入口默认首页
- **核心特性**：URL 不变，无页面跳转，保持沉浸感

## 8. 注意事项

### 8.1 模块边界

| 模块1负责 | 模块1不负责 |
|-----------|-------------|
| 羊皮纸 UI 渲染与布局 | 联机通信（WebSocket）|
| 面板切换逻辑与本地交互 | 数据持久化/数据库 |
| UI 状态管理（当前面板） | 跨模块业务状态（房间状态等）|
| 创建/加入房间的表单 UI | 房间创建的业务逻辑（由模块2处理）|
| 好友列表的展示 | 好友数据的获取与同步（由模块2提供接口）|

### 8.2 与模块2的接口约定

模块1 通过模块2提供的事件/API 接口获取数据：


- 具体的 WebSocket 连接、消息广播、断线重连由模块2处理

### 8.3 视觉实现建议（破旧卷轴羊皮纸方案）

#### 实现优先级

**P0 — 核心质感（必须实现）**：
- **羊皮纸基础纹理**：SVG `feTurbulence` (`fractalNoise`, `baseFrequency="0.04"`) + `feColorMatrix` 调色 → 叠加在底色 `#E8D5B7` 上，`opacity: 0.25`
- **不规则破损边缘**：SVG `clipPath` 定义撕裂路径，上下左右各约 3-6 个随机锯齿，配合烧焦渐变（`#4A3728` → `#2D1F17`）
- **卷轴木棒**：顶部/底部 `div`，`background: linear-gradient(to bottom, #5C3D2E, #3B2515, #6B4A2E)` 模拟木纹，`border-radius` 做圆柱感，加投影
- **暗角渲染**：`inset box-shadow: 0 0 80px rgba(45, 31, 23, 0.2)` + 四角径向渐变加深

**P1 — 做旧细节（应实现）**：
- **水渍/污渍**：绝对定位的 `<div>` 覆盖层，使用 `radial-gradient` 模拟不规则褐色水渍，`opacity: 0.1~0.2`，位置写死（或通过伪随机种子固定）
- **折痕线**：SVG `<line>` / `<path>` 元素，`stroke: #8B7355`, `stroke-width: 1`, `opacity: 0.4`，45° 斜向或横向排布
- **边角卷曲**：`::before` 伪元素 + `transform: rotate(-3deg) perspective(200px) rotateY(-5deg)` 模拟右上角轻微卷起，加下方投影
- **字体加载**：Google Fonts 引入 `IM Fell DW Pica`（标题）和 `Crimson Text`（正文），配置 `@font-face` 备用方案

**P2 — 渲染增强（锦上添花）**：
- **蜡烛光晕背景**：整体页面添加暖色径向渐变（`#F4C674` → 透明），从中心向外，模拟烛光照射感
- **首字母装饰**：CSS `:first-letter` + 装饰字体放大，或独立 `<span>` + 圆形花纹边框 SVG
- **四角纹章**：SVG 绘制盾牌/龙爪图案，颜色 `#9A7B4F`（黄铜金），`opacity: 0.6`，绝对定位贴四角
- **封蜡效果**：按钮加 `::before` 伪元素，`radial-gradient` 模拟蜡面光泽，中心 SVG 压印纹章
- **打开动画**：羊皮纸从上下卷轴向中间展开（`scaleY: 0 → 1` + `transform-origin: center`）

#### 实现工具链建议

| 效果 | 推荐方案 | 备选方案 |
|------|---------|---------|
| 纸张噪声纹理 | SVG `<filter>` + `feTurbulence` | CSS `backdrop-filter: url(...)` |
| 不规则破损边缘 | SVG `<clipPath>` + `<path>` | CSS `clip-path: polygon(...)` |
| 水渍/污渍 | CSS `radial-gradient` 多层叠加 | 预制 PNG 纹理图（性能更佳） |
| 折痕裂纹 | SVG `<line>/<path>` 内联 | CSS `::before` 伪元素 |
| 边角卷曲 | CSS `transform: perspective` + 阴影 | 预制阴影 PNG |
| 蜡烛光晕 | CSS 径向渐变叠加 | Three.js 点光源（酒馆场景） |
| 字体 | Google Fonts（开发阶段） | 本地字体文件（生产阶段） |
