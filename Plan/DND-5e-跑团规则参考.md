# D&D 5e 线下跑团规则参考（DNDBOX 设计参考）

**版本**：v1.0
**日期**：2026-08-13
**用途**：为 DNDBOX 的规则引擎、AI GM 行为与后续剧本设计提供线下 D&D 跑团（5e）的规则参考。内容为对官方规则（Player's Handbook / Dungeon Master's Guide / Basic Rules / SRD，2014 与 2024 版）的整理与转述，供内部设计参照，非官方译文。

---

## 1. 核心机制总览

### 1.1 游戏节奏（回合循环）

2024 Basic Rules 明确的基本循环：

1. **DM 描述场景**：告诉玩家在哪里、周围有什么。
2. **玩家宣告动作**：角色要做什么。非战斗时 DM 确保每个角色都有行动机会；战斗时按先攻轮流。
3. **DM 裁定并叙事结果**：简单的事直接成功；有不确定性和后果的才掷骰。

> DNDBOX 现状完全对齐：`GM 描述 → 玩家输入 → 规则引擎裁定/掷骰 → AI 叙事`。

### 1.2 三大支柱（Three Pillars）

社交互动（Social Interaction）、探索（Exploration）、战斗（Combat）。三者中社交规则最少，官方刻意不把它公式化，以保沉浸。

### 1.3 检定体系

| 概念 | 说明 |
|------|------|
| **能力检定**（Ability Check） | `d20 + 属性调整 + 熟练加值（若擅长）`，结果 ≥ DC 即成功 |
| **对抗检定**（Contest） | 双方各掷一次比高低（如潜行 vs 感知） |
| **被动检定**（Passive Check） | `10 + 加值`（优势 +5 / 劣势 −5），用于"不提示玩家掷骰"的隐蔽判定 |
| **DC（难度等级）** | 5 非常简单 / 10 简单 / 15 中等 / 20 困难 / 25 极难 / 30 几乎不可能 |

**"10/15/20 规则"**：日常任务 DC 10，真正挑战 DC 15，困难事 DC 20——覆盖 90% 情境。

### 1.4 何时掷骰 / 何时不掷骰（DMG 指引）

掷骰前问两个问题：
1. **这个任务能以有趣的方式失败吗？** 不能 → 不掷骰，直接成功。
2. **成功是否可能？** 不可能 → 不掷骰，直接描述失败。

> DNDBOX 对应：`只在有意义时掷骰`铁律 + `_handle_check` 的无风险/无希望分支。

## 2. 探索（Exploration）

### 2.1 被动感知（Passive Perception）

- 公式：`10 + 感知调整（+ 感知熟练）`；优势 +5、劣势 −5。
- 用途：玩家没有主动搜索时，"永远在线"地察觉明显之物（隐藏的陷阱、埋伏、异响）。
- 价值：**避免用"掷个侦察"来提示玩家"这里有东西"**——被动感知直接给提示，玩家再决定是否主动调查。

> DNDBOX 对应：`run_passive_checks`（进入新地点时被动察觉/被动调查与 hidden DC 比对）。隐藏信息模型与官方一致。

### 2.2 时间尺度（2024 DMG）

- **回合**（round）：战斗与快速情境，6 秒。
- **分钟**：地城/城镇内移动。
- **小时 / 天**：野外跋涉与长途旅行。
- 用途：追踪法术时限、定时触发事件（如"门开启 1 分钟后关闭""警报响起 2d4 分钟后增援到达"）。

> DNDBOX 对应：目前 `game_time` 仅做历史排序；**后续可参考**：延迟反应（notice_after）、事件队列（P1 待实现）。

### 2.3 探索动作（2024）

搜索（Search）、研究（Study）、使用（Utilize）、协助（Help）。非战斗时很少需要严格动作规则，记住"一个角色一次只能做一件事"即可。

## 3. 社交互动（Social Interaction）

### 3.1 NPC 态度（DMG p.244 / SRD 2024）

每个 NPC 对玩家有一个起始态度：

| 2014 DMG | 2024 SRD | 行为倾向 |
|----------|----------|----------|
| Helpful（乐于助人） | Friendly | 乐于帮助；涉及个人风险的任务需要成功的魅力检定 |
| Indifferent（中立） | Indifferent | 不关心；要靠互动赢得 |
| Hostile（敌对） | Hostile | 倾向于阻碍 |

社交互动通过**角色扮演 + 技能检定**两条途径推进：
- 角色扮演决定 NPC 如何反应（懦弱的匪徒怕威胁，顽固的商人烦纠缠）。
- 检定（游说/欺瞒/威吓）用于角色扮演无法覆盖的部分。

### 3.2 说服 ≠ 心灵控制

成功的游说改变 NPC 的**态度与意愿**，不改变其**核心信念、职业底线与自我保全本能**。商人不会把店白送，卫兵不会放走重犯。

> DNDBOX 对应：`说服≠心灵控制`铁律 + ④NPC 扮演细则。**后续可参考**：正式引入态度分级（Friendly/Indifferent/Hostile）+ 态度改善机制（P1 待实现）。

### 3.3 洞悉 vs 欺瞒

- NPC 会按剧本撒谎/隐瞒；玩家**洞悉（Insight）**成功可察觉破绽。
- 洞悉是感知检定，对抗的是 NPC 的欺瞒意愿，不是直接读心——只能判断"对方是否在隐瞒/是否可信"，不能读出内容。

## 4. 潜行与隐匿（Stealth & Hiding）

### 4.1 官方规则

- 躲藏时做**敏捷（隐匿）检定**；隐匿者的隐匿检定总值**成为感知检定寻找它的 DC**（SRD 原文：a hiding creature's Stealth check sets the DC for Perception checks to find it）。
- 被主动搜索时：隐匿检定对抗搜索者的感知检定（双方都掷）。
- 无人主动搜索时：对抗观察者的**被动感知**。
- 只要目标能清楚看见你、或你发出明显噪音（喊叫、踢翻花瓶），就不能隐藏。

### 4.2 多观察者处理

规则上潜行要对抗**每个**观察者。引擎可简化为一次检定 vs **在场观察者中最高被动感知**（躲过最警觉的眼睛）。

> DNDBOX 对应：`witness_stealth_dc`（当前地点在场 NPC 最高被动感知+警觉）。与官方理念一致。

## 5. 偷窃与巧手（Sleight of Hand）

### 5.1 官方做法：对抗目标感知

偷窃（pickpocket）官方指引即"**巧手检定对抗目标的感知**"（Sleight of Hand check against the target's Perception）。DC 来自观察者，不是物品本身。

### 5.2 情境 DC 参考（社区整理，供剧本设计参考）

| DC | 巧手动作 |
|----|----------|
| 9 | 把纸条/硬币悄悄放到别人身上 |
| 12 | 小动作戏法——藏起一枚硬币（对抗旁观者感知） |
| 15 | 顺走一件无人看管的小物件（对抗旁观者感知） |
| 18 | 从某人身上顺走小物件、往杯中下药 |
| 24 | 从鞘中抽出武器 |

> DNDBOX 对应：偷窃 DC = 目标被动感知 + 警觉（物品显式 difficulty 可覆盖）。**后续可参考**：给不同偷窃情境（货架/身上/武器）预设难度增量。

## 5.3 被擒、挣脱与追捕（被当场抓住后）

### 5.3.1 被擒（Grappled）

- 偷窃被**当场抓住** ≈ 进入**被擒**状态：被抓者的**移动速度变为 0**，不能直接离开。
- 5e 擒抱：抓取者做**力量（运动）检定，对抗目标的运动或体操**，成功则目标被擒（速度 0）。

### 5.3.2 挣脱（Escape a Grapple）

- 被抓者用动作做**力量（运动）或敏捷（体操）检定，对抗抓取者的力量（运动）**。
- 成功 → 挣脱（可移动）；失败/平手 → 保持被擒。
- **挣脱是逃跑的前置**——不能绕过它直接走。

> DNDBOX 对应：对峙中玩家说"逃跑" → 挣脱检定（运动/体操 vs 原告力量，缺省力量 10）。

### 5.3.3 逃跑与追捕（Chase）

- 挣脱后移动离开 → 进入**追逐**：做**隐匿检定 vs 追兵（及在场目击者）被动感知**。
- 失败 → 被追上 / 被擒回；成功 → 脱身。

> DNDBOX 对应：逮捕流程 summoned 阶段 flee → 隐匿 vs 卫兵被动感知（town-guard 12）。

### 5.3.4 挣脱后的处置（受害者会叫守卫）

- 挣脱成功后，受害者通常会**当场呼叫卫兵/路人**（"抓小偷！"）→ 处置升级为逮捕流程。
- **拒捕**（Resisting Arrest）在多数律法中是**单独的加重罪**（罚款/刑期翻倍）。

> DNDBOX 对应：挣脱成功 → 自动进入逮捕 summoned 阶段（卫兵赶来），玩家可在赶来中再 flee 脱身，或等待卫兵到场三选一（服从/逃跑/反抗）。

## 6. 战斗（Combat）

> DNDBOX 当前战斗为 P1 待实现，此处列核心要素供设计时参考。

| 要素 | 规则 |
|------|------|
| **先攻** | 战斗开始各掷先攻（d20+敏捷调整），按序行动 |
| **动作经济** | 每回合：1 动作 + 1 附赠动作 + 1 反应 + 移动 |
| **攻击检定** | `d20 + 熟练 + 属性调整` vs 目标 **AC** |
| **AC** | 10 + 敏捷调整；穿甲后按甲种计算（轻甲加敏调/中甲最多+2/重甲不加） |
| **伤害** | 命中后掷武器伤害骰 + 属性调整；**自然 20** 重击（伤害骰翻倍） |
| **优势/劣势** | 掷两次取高/低；来源可叠加但结果只取一重 |
| **HP 归零** | 倒地昏迷，需成功死亡豁免（10 为界，三次成功稳定/三次失败死亡） |

> DNDBOX 装备系统已实现：AC/攻击加值/伤害骰按 D&D 5e 推导（§6.4），与上表一致。战斗遭遇动作未实现。

## 7. DM 职责与裁定

### 7.1 Rulings, not rules（裁定而非死规则）

规则是指南不是物理学。DM 是最终裁定者，用"规则的精神"而非"规则的文字"裁决。裁定要**公平、一致**，对 NPC 与玩家同一把尺。

### 7.2 失败后果（Ability Checks 官方口径）

检定失败 = **对目标没有进展**，或**有进展但伴随由 DM 决定的代价**——两者都是合法结果，"每次失败必有戏剧性转折"不是 5e 的默认。

> DNDBOX 对应：`失败如实叙事`铁律 + `失败后果由数据决定`（规则引擎/场景数据为准，"没发现"是合法结果）。

### 7.3 信息控制

- **被动感知用于不提示掷骰的发现**（避免玩家闻骰而动）。
- 隐藏信息（陷阱、伏击、秘密）通过被动感知/主动调查逐步释放。
- 地图与情报有"DM 专用层"与"玩家层"，不要把所有信息一次性倒给玩家。

> DNDBOX 对应：`信息控制`细则（只给应知道的信息、侦察无发现就明说、危险预警）。

## 8. 与 DNDBOX 现状的映射

### 8.1 已对齐

| 官方概念 | DNDBOX 落地 |
|----------|-------------|
| 回合循环（描述→宣告→裁定） | adventure.html 叙事日志 + 自由输入 + 规则引擎 |
| 被动感知 | `run_passive_checks`（进入地点自动比对 hidden DC） |
| 潜行 vs 被动感知 | `witness_stealth_dc`（目击者最高被动感知+警觉） |
| 巧手对抗目标感知 | 偷窃 DC = 目标被动感知 + 警觉 |
| 说服≠心灵控制 | AI GM 铁律 + NPC 目标/秘密/性格注入 |
| 何时掷骰 | `只在有意义时掷骰` + 规则引擎无风险/无希望分支 |
| 失败无进展/有代价 | `失败后果由数据决定`（警觉/敌对/状态变化） |
| DC 表 | `DC 分级参照`（10/15/20/25/30） |
