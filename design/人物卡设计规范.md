# 人物卡设计规范

**版本**：v1.1  
**用途**：本文档描述 DNDBOX 人物卡的设计原则、CSS 类体系、HTML 结构和数据格式，供 AI 生成新人物卡时参考。

---

## 1. 设计原则

### 1.1 配色

所有颜色通过 CSS 变量统一管理，与大厅页面共用：

```css
--ink:        #3d2b1f;   /* 深墨色 — 标题、正文 */
--ink-soft:   #6b4e3d;   /* 浅墨色 — 辅助文字 */
--paper:      #faf6ee;   /* 纸张底色 */
--paper-light:#fdfbf7;   /* 浅纸张 — 卡片背景 */
--paper-card: #fdfbf7;   /* 卡片背景（同 paper-light） */
--accent:     #8b5a2b;   /* 强调色 — 按钮、高亮、图标 */
--accent-light:#d69a5c;   /* 浅强调色 — 渐变用 */
--border:     rgba(61, 43, 31, 0.12); /* 边框 */
--shadow:     rgba(61, 43, 31, 0.12); /* 阴影 */
--slot:       rgba(61, 43, 31, 0.05); /* 装备槽背景 */
```

### 1.2 设计理念

- **羊皮纸质感**：暖米色底色 + 轻微噪点纹理，深棕色文字而非纯黑
- **克制装饰**：不做过度做旧效果，保持干净可读
- **信息分层**：标题深色粗体，正文浅色，强调用橙色
- **卡片容器**：白色半透明圆角卡片，细边框 + 轻微阴影
- **一致性**：同一套 CSS 变量驱动所有颜色，全局统一

### 1.3 字体

```css
font-family: "Noto Serif SC", "Source Han Serif SC", "STSong", "SimSun", Georgia, serif;
```

衬线字体优先，营造中世纪手稿感。

## 2. 人物卡整体结构

人物卡位于 `lobby.html` 的 `panel-content[data-panel="characters"]` 内，整体嵌套如下：

```
panel-content[data-panel="characters"]
  page-header (标题 + 描述)
  .container (max-width: 900px)
    char-card (角色概要卡片：头像 + 装备槽 + 战斗数据)
    tabs (物品栏 | 职业&特性 | 熟练加值 | 技能&法术 | 人物背景)
    tab-content × 5 (对应五个选项卡)
```

每个 `tab-content` 用 `id` 与 `button[data-tab]` 关联，由 JS 切换显示。

## 5. 交互系统 JS

### 5.1 选项卡切换

```javascript
document.querySelectorAll('.tab').forEach(tab => {
  tab.addEventListener('click', () => {
    const parent = tab.closest('.panel-content');
    parent.querySelectorAll('.tab').forEach(t => t.classList.remove('active'));
    parent.querySelectorAll('.tab-content').forEach(c => c.classList.remove('active'));
    tab.classList.add('active');
    const target = tab.getAttribute('data-tab');
    if (target) {
      document.getElementById(target)?.classList.add('active');
    }
  });
});
```

- 作用域限定在 `.panel-content` 内
- `data-tab` 属性值与 `tab-content` 的 `id` 对应
- 切换有 0.3s 淡入动画

### 5.2 特性展开/折叠

```javascript
document.querySelectorAll('.feature-list li').forEach(li => {
  li.addEventListener('click', function(e) {
    e.stopPropagation();
    this.classList.toggle('expanded');
  });
});
```

- 点击特性行切换 `expanded` 类
- `expanded` 时箭头旋转 180°，`.feature-detail` 显示
- `stopPropagation` 防止事件冒泡

### 5.3 物品悬浮提示

物品卡片（`.item-card`）和技能方块（`.skill-block`）共享同一个 `.item-tooltip` 浮层：

- **触发**：鼠标停留超过 500ms
- **位置**：跟随鼠标，自动避让屏幕边界
- **消失**：鼠标离开、滚动页面
- **物品提示内容**：物品名称 + 已装备状态 + 详细属性（待补充）
- **技能提示内容**：技能名称 + 技能详情（待补充）

### 5.4 物品右键菜单

右键点击 `.item-card` 弹出操作菜单：

- **装备/卸下**：根据当前装备状态自动切换文字。点击后动态添加/移除 `.item-equipped` 元素
- **丢弃**：占位操作
- **赠送**：占位操作
- 点击菜单外关闭，滚动页面关闭
- 菜单自动避让屏幕边界

### 5.5 装备状态切换实现

```javascript
if (action === 'equip') {
  const existing = card.querySelector('.item-equipped');
  if (existing) {
    existing.remove();       // 卸下：移除标记
  } else {
    const eq = document.createElement('div');
    eq.className = 'item-equipped';
    eq.textContent = '已装备';
    const nameEl = card.querySelector('.item-name');
    if (nameEl && nameEl.parentNode) {
      nameEl.parentNode.insertBefore(eq, nameEl);  // 装备：插入标记
    }
  }
}
```

## 6. 生成新人物的步骤

1. **确定数据**：角色名、种族、职业、等级、属性值、生命值、护甲等级、装备、物品、技能、法术、背景故事
2. **复用结构**：拷贝上述 HTML 模板，填入数据
3. **保持 CSS 变量**：不要硬编码颜色，始终使用 `var(--ink)` 等
4. **熟练标记**：属性值和技能值中，熟练项加 `★`（`ability-star`）和 `highlighted` 类
5. **技能加值符号**：正值加 `.positive` 类（橙色），负值加 `.negative` 类（红色），0 不加
6. **装备槽 SVG**：可复用现有槽位图标，或保持虚线空槽
7. **特性展开**：每个 `feature-list li` 后紧跟 `<div class="feature-detail">`，箭头 SVG 为固定模板
8. **故事文本**：`bg-story` 段落首行自动缩进 2em，注意分段
