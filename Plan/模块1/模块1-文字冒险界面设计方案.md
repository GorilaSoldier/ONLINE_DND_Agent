**文档版本**：v1.1  
**编写日期**：2026-07-27  
**更新日期**：2026-07-28（7×7 Grid + 三栏布局已实现）  
**所属模块**：模块1 - 前端多端交互与沉浸式界面模块

---

## 1. 概述

### 1.1 设计目标

为 DNDBOX 的非战斗阶段提供纯文字 + 按钮的交互界面，玩家通过按钮在不同地点间导航，与 NPC 交互，推进剧情。

### 1.2 核心设计理念

| 要素 | 设计 |
|------|------|
| **导航** | 中央当前地点，上下左右各最多 3 格（7×7 Grid），按钮间用 CSS `::after` 线条相连 |
| **场景** | 顶部旁白式描述文字，根据剧情动态变化 |
| **NPC** | 中部面板列表（导航区下方），点击弹出信息面板（交谈/交易/任务） |
| **数据** | 全 JSON 驱动，剧本独立为数据文件，换剧本 = 换 JSON |
| **布局** | 三栏布局：左侧面板（队伍+任务占位）+ 中央框架（导航+ NPC）+ 右侧面板（角色卡） |

### 1.3 页面定位

- 文件：`adventure.html`（独立页面）
- 复用 lobby.html 的色彩体系（CSS 变量）
- 后续从 lobby.html 点击"开始冒险"跳转进入，携带剧本 ID 参数

### 2.1 左侧面板（先空置）

- CSS 变量：`--left-panel-w`（默认 240px，拖拽范围 160px~500px）
- 预留分区：`队伍成员` + `当前任务`，虚线占位框
- 宽度持久化到 `localStorage.adventure-left-panel-w`

### 2.2 中央框架区

- `flex: 1`，`min-width: 300px`（防面板拖拽过大时塌陷）
- 内嵌 `.nav-frame` 框体：`border: 1px solid var(--border); border-radius: 16px; margin-top: 80px; min-height: 200px`
- 框体内放置 7×7 导航 Grid（`grid-template-rows: repeat(7, 68px); gap: 10px`）
- Grid 下方为 NPC 列表区

### 2.3 右侧面板（角色卡）

- CSS 变量：`--right-panel-w`（默认 240px，拖拽范围 160px~500px）
- 数据来源：`localStorage.currentCharacter`（JSON）
- 显示：头像一个字、名称、种族·职业·等级、HP/HP-max、AC、先攻加值
- 宽度持久化到 `localStorage.adventure-right-panel-w`

### 2.4 拖拽把手

- 面板与中央区域之间各有一个 `6px` 宽的 `.resize-handle`
- 鼠标悬停显示金色半透明竖条，拖动时 `cursor: col-resize`
- 面板宽度自动保存到 localStorage，刷新恢复
- 恢复时钳制宽度：不超过 `(window.innerWidth - 320) / 2`，保证中央至少 320px

### 3.2 导航规则

- 每个节点定义 `up / down / left / right` 四个方向的邻居 ID
- `null` 表示该方向无连接
- 以当前地为中心，沿各方向链式漫游最多 3 格（7×7 Grid）
- 房间内自动显示 "↩ 离开" 按钮（查找父建筑的外部出口）
- Esc 键返回上一级

## 4. 7×7 导航 Grid

### 4.1 链式漫游规则

```js
function walkChain(id, dir, maxDepth) {
  const chain = [];
  let cur = id;
  for (let i = 0; i < maxDepth; i++) {
    const loc = findLocation(cur);
    if (!loc || !loc.neighbors || !loc.neighbors[dir]) break; // 截断
    const nextId = loc.neighbors[dir];
    chain.push(nextId);
    cur = nextId;
  }
  return chain; // [距离1, 距离2, 距离3]
}
```

- **岔路截断**：只严格沿指定方向走，不跳转到其他方向
- **null 截断**：该方向邻居为 null → 停止

### 4.2 Grid 结构

```
  列1    列2    列3    列4    列5    列6    列7
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│      │      │ (3上) │      │      │      │      │  ← 行1
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │ (2上) │      │      │      │      │  ← 行2
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │ (1上) │      │      │      │      │  ← 行3
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│(3左) │(2左) │(1左) │  ●   │(1右) │(2右) │(3右) │  ← 行4: 当前行
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │ (1下) │      │      │      │      │  ← 行5
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │ (2下) │      │      │      │      │  ← 行6
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │ (3下) │      │      │      │      │  ← 行7
└──────┴──────┴──────┴──────┴──────┴──────┴──────┘
```

- 行4 列4（中心）= 当前地（`accent` 高亮按钮）
- 行1/2/3 列4 = 上方 3/2/1 格
- 行5/6/7 列4 = 下方 1/2/3 格
- 行4 列1/2/3 = 左侧 3/2/1 格
- 行4 列4/5/6 = 右侧 1/2/3 格
- 其余格子为空（不渲染）

### 4.3 连线规则

- `gap: 10px` 提供格子间距
- `.nav-cell.has-line-down::after`：`bottom: -10px; width: 2px; height: 10px` 填充竖线
- `.nav-cell.has-line-right::after`：`right: -10px; width: 10px; height: 2px` 填充横线
- 只在与相邻格子非空时添加对应 class
- 线条颜色：`rgba(61, 43, 31, 0.35)`

### 4.4 按钮样式

- 当前地：`accent` 背景，白色文字，`font-size: 14px`，无固定宽度（自适应）
- 邻居按钮：`paper-card` 背景，`font-size: 12px`，无固定宽度
- 出口按钮（房间内）：`border-style: dashed; border-color: var(--accent); color: var(--accent)`
- 空位置：渲染空 `<div class="nav-cell"></div>`

### 4.5 预计算优化

```js
const chainCache = {}; // { "locationId:up": ["id1","id2","id3"], ... }

// 加载数据时一次性预计算所有节点的四方向链
for (const id of Object.keys(allLocations)) {
  for (const dir of ['up','down','left','right']) {
    chainCache[`${id}:${dir}`] = walkChain(id, dir, 3);
  }
}
```

`renderNav()` 直接查缓存，O(1) 渲染。

## 9. 数据流

```
adventure.html 加载
  │
  ├─ fetch /data/adventure/world-forgotten-realms.json
  │   └─ 展平 locations + rooms 到 allLocations{}
  │   └─ 预计算所有节点四方向链到 chainCache{}
  │
  ├─ fetch /data/adventure/npcs-forgotten-realms.json
  │   └─ 解析 NPC 索引
  │
  ├─ renderAll()
  │   ├─ renderScene()          → 场景描述（scene_banner）
  │   ├─ renderNav()            → 7×7 Grid + 连线
  │   └─ renderNpcs()           → NPC 卡片列表
  │
  ├─ renderRightPanel()         → 角色卡（localStorage.currentCharacter）
  │
  └─ 用户交互
      ├─ 点击导航按钮 → navigateTo(targetId) → renderAll()
      ├─ 点击出口按钮 → navigateTo(exitTarget) → renderAll()
      ├─ Esc 键 / 返回  → goBack() → renderAll()
      └─ 点击 NPC 卡片  → openNpcModal(npcId)
          ├─ 交谈 → 刷新 greeting
          └─ 打听消息 → 展开 rumors 列表
```
