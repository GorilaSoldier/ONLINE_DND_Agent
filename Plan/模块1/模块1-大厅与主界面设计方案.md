# 模块1：大厅与主界面设计方案

**文档版本**：v2.0  
**编写日期**：2026-07-13  
**所属模块**：模块1 - 前端多端交互与沉浸式界面模块

---

## 1. 方案概述

### 1.1 设计目标

为 DNDBOX（AI 跑团辅助平台）打造一套简洁、优雅的羊皮纸风格界面，包含登录/注册页和单页大厅两个页面，整体视觉干净克制，避免过度装饰。

### 1.2 核心设计理念

| 场景 | 风格 | 说明 |
|------|------|------|
| **登录页** | 轻量羊皮纸 | 米白色纸张纹理背景 + 网格线，居中登录/注册入口，页脚装饰性文字 |
| **大厅页面** | 黑色侧栏 + 纸张内容区 | 左侧黑色固定侧边栏导航，右侧浅米色内容区，单页 Tab 切换五个面板 |

### 1.3 两个核心场景

- **场景1（login.html）**：登录/注册入口页，羊皮纸质感背景，简洁的登录/注册双按钮
- **场景2（lobby.html）**：单页大厅，黑色侧边栏 + 五个子面板 Tab 切换（冒险日记、我的好友、游戏剧本、房间列表、个人设置）

---

## 2. 技术选型

| 技术维度 | 选型 | 理由 |
|----------|------|------|
| **前端方案** | 纯 HTML + CSS + Vanilla JS | MVP 阶段零依赖，快速迭代，无构建工具开销 |
| **样式方案** | CSS 自定义属性（CSS Variables） | 统一管理色彩、阴影等设计令牌 |
| **图标方案** | 内联 SVG | 零额外请求，支持 CSS 变量染色 |
| **页面过渡** | CSS transition + class toggle | 跨页面淡入淡出效果，轻量丝滑 |
| **面板切换** | JS classList toggle + data 属性 | 单页内导航项切换，无 URL 变化 |

---

## 3. 色彩体系

设计令牌统一通过 CSS 自定义属性管理，两个页面共享相同配色。

```css
:root {
  --ink:       #3d2b1f;   /* 深墨色 — 标题、正文 */
  --ink-soft:  #6b4e3d;   /* 浅墨色 — 辅助文字 */
  --paper:     #faf6ee;   /* 纸张底色 — 背景主色 */
  --paper-light: #fdfbf7; /* 浅纸张 — 卡片背景 */
  --paper-dark: #e5dbca;  /* 深纸张 — 暗区 */
  --accent:    #8b5a2b;   /* 强调色 — 按钮、图标 */
  --border:    rgba(61, 43, 31, 0.12); /* 边框 */
  --shadow:    rgba(61, 43, 31, 0.12); /* 阴影 */
}
```

**设计原则**：低饱和度暖色调，模拟羊皮纸质感的米白色系，文字用深棕色而非纯黑，柔和自然。

## 4. 登录页设计（login.html）

### 4.1 布局

```
┌─────────────────────────────────────────────┐
│  [DNDBOX]                          ← header │
│                                             │
│                                             │
│              [品牌图标]                       │
│              DNDBOX                         │
│         简短描述文字                          │
│                                             │
│         [登录]  — 或 —  [注册]              │
│                                             │
│              ❧                              │
│          吟游诗人正在谱曲                     │
│                                             │
└─────────────────────────────────────────────┘
```

### 4.2 视觉特点

- 羊皮纸底色 + SVG noise 纹理 + 网格线叠加，营造纸张质感
- Logo 固定在左上角，页面缩放位置不变
- 主内容垂直居中，页脚紧跟在按钮下方（非页面底部）
- 按钮 hover 有弹起 + 金色魔法光晕效果
- 页面离开时缩小淡出，进入大厅时放大淡入

### 4.3 交互

- 点击「登录」或「注册」→ 0.25s 淡出 + 缩小动画 → 跳转 lobby.html
- lobby.html 加载后 0.3s 淡入 + 放大动画

## 5. 大厅页面设计（lobby.html）

### 5.1 整体布局

```
┌──────────┬──────────────────────────────────────────┐
│          │  [topbar]                        加入冒险 │
│          ├──────────────────────────────────────────│
│ 黑色     │                                          │
│ 侧边栏   │          [当前面板内容区]                  │
│ 240px    │                                          │
│ 固定     │    ┌─ 统计卡片 × 4 ──────────────┐       │
│          │    └──────────────────────────────┘       │
│ 冒险日记 ●│                                          │
│ 我的好友  │    ┌─ 任务列表 ──┬── 冒险小队 ──┐       │
│ 游戏剧本  │    │              │              │       │
│ 房间列表  │    └──────────────┴──────────────┘       │
│ 个人设置  │                                          │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

### 5.2 侧边栏

- 纯黑背景（`#000000`），240px 宽，固定定位
- DNDBOX 品牌标识 + 导航项（带内联 SVG 图标）
- 激活项：左侧橙色竖线指示 + 白色半透明背景
- 文字和图标为白色半透明，hover/active 时变亮

### 5.3 五个子面板

| 面板 | data-panel | 状态 | 说明 |
|------|-----------|------|------|
| 冒险日记 | `adventure` | 已完成 | 默认面板，统计卡片 + 任务列表 + 冒险小队 |
| 我的好友 | `friends` | 占位 | 后续实现好友列表、在线状态、邀请功能 |
| 游戏剧本 | `scripts` | 占位 | 后续实现剧本浏览、筛选、下载 |
| 房间列表 | `rooms` | 占位 | 后续实现房间创建、浏览、加入 |
| 个人设置 | `settings` | 占位 | 后续实现个人信息与偏好管理 |

### 5.4 面板切换机制

纯 JS 实现，无框架依赖：
- 每个 `.nav-item` 通过 `data-panel` 属性对应一个 `.panel-content`
- 点击导航项：移除所有 `.active`，给当前项和对应面板添加 `.active`
- CSS 通过 `.panel-content { display: none }` / `.panel-content.active { display: block }` 控制显隐
- 无 URL 变化，无页面刷新，侧边栏始终可见

### 5.5 冒险日记面板（默认面板）

- 顶部：页面标题 + 描述文字
- 四个统计卡片：情报数量、剧本章节、公共资产、区域地图
- 左侧：当前任务列表（可滚动，带图标、标签、时间）
- 右侧：冒险小队成员列表（头像、名称、职业等级）
