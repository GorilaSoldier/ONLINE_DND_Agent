# 模块1：文字冒险界面设计方案

**文档版本**：v1.0  
**编写日期**：2026-07-27  
**所属模块**：模块1 - 前端多端交互与沉浸式界面模块

---

## 1. 概述

### 1.1 设计目标

为 DNDBOX 的非战斗阶段提供纯文字 + 按钮的交互界面，玩家通过按钮在不同地点间导航，与 NPC 交互，推进剧情。

### 1.2 核心设计理念

| 要素 | 设计 |
|------|------|
| **导航** | 中央当前地点，四周按钮按方位（上下左右）连接，按钮间用简单线条相连 |
| **场景** | 顶部旁白式描述文字，根据剧情动态变化 |
| **NPC** | 中部面板列表，点击弹出信息面板（交谈/交易/任务） |
| **数据** | 全 JSON 驱动，剧本独立为数据文件，换剧本 = 换 JSON |

### 1.3 页面定位

- 新文件：`adventure.html`（独立页面）
- 复用 lobby.html 的色彩体系（CSS 变量）
- 后续从 lobby.html 点击"开始冒险"跳转进入，携带剧本 ID 参数

```css

/* 新增：连接线颜色 */
```

**按钮尺寸**：
- 当前地点按钮：`120px × 48px`，高亮强调色背景
- 四周导航按钮：`120px × 44px`，纸张色卡片
- NPC 卡片：`min-width: 96px`，弹性排列
- 连接线：`2px solid`，长度约 `40px`

### 4.1 层级模型

```

  ├── 凡达林镇（城镇层）
  │   ├── 大街（街道层）
  │   │   ├── 石丘旅馆（建筑层）
  │   │   │   ├── 大厅（房间层）
  │   │   │   │   └── NPC: 托布拉, 弗雷德...
  │   │   │   └── 客房
  │   │   ├── 狮盾补给站
  │   │   └── ...
  │   └── ...
  └── 绝冬森林（野外层）
      ├── 克拉摩窝点
      └── ...
```

### 4.2 导航规则

- 每次只显示**当前层**的节点
- 每个节点定义 `up / down / left / right` 四个方向的邻居
- `null` 表示该方向无连接
- "返回"按钮回到父节点（上一层级）

## 6. 导航区渲染逻辑

### 6.1 CSS 线条方案（选 CSS，代码少于 SVG）

使用 `::before` / `::after` 伪元素画连接线：

```
          [up]             ← 上邻居按钮
           │               ← 伪元素竖线
[left] ─── [● 当前] ─── [right]
           │               ← 当前地居中，高亮
         [down]            ← 下邻居按钮
```

**实现要点**：
- 导航区是一个 CSS Grid，5 个单元格（十字形）
- 中央单元格放当前地按钮
- 四周单元格放邻居按钮（`null` 则留空）
- 每个非空邻居按钮用 `::before` 画连线指向中央

### 6.2 伪元素连线示例

```css
.nav-btn { position: relative; }
.nav-btn[data-dir="up"]::after {
  content: "";
  position: absolute;
  bottom: -40px; left: 50%;
  width: 2px; height: 40px;
  background: var(--line-color);
  transform: translateX(-50%);
}
/* down / left / right 同理调整方向 */
```

### 6.3 Grid 布局

```css
.nav-grid {
  display: grid;
  grid-template-areas:
    ".    up    ."
    "left curr right"
    ".   down   .";
  grid-template-columns: 140px 140px 140px;
  grid-template-rows: 88px 88px 88px;
  gap: 0;
  justify-content: center;
  align-items: center;
}
```

## 8. 场景描述区

### 8.1 布局

```html
<div class="scene-banner">
  <p id="scene-text">石丘旅馆的壁炉噼啪作响...</p>
</div>
```

### 8.2 样式

- 半透明深色背景条，跨整个内容区宽度
- 居中斜体文字，配书本图标
- 首次进入新地点时插入（不重复）
- 剧情事件触发时动态更新文字

### 8.3 实现

```js
function updateScene(location) {
  const el = document.getElementById('scene-text');
  if (location.scene_text) {
    el.textContent = location.scene_text;
    el.style.opacity = '0';
    requestAnimationFrame(() => {
      el.style.transition = 'opacity 0.5s ease';
      el.style.opacity = '1';
    });
  }
}
```

## 10. 数据流

```
adventure.html 加载
  │
  ├─ fetch /data/adventure/world-forgotten-realms.json
  │   └─ 解析 locations, 构建地点图
  │
  ├─ fetch /data/adventure/npcs-forgotten-realms.json
  │   └─ 解析 NPC 数据, 构建 NPC 索引
  │
  ├─ 确定起始地点 (start_location)
  │   └─ renderLocation(currentLocationId)
  │       ├─ updateScene(location.scene_text)          → 场景描述
  │       ├─ renderNavGrid(location.neighbors)         → 导航按钮 + 连线
  │       └─ renderNpcList(location.npcs)              → NPC 卡片列表
  │
  └─ 用户交互
      ├─ 点击导航按钮 → navigateTo(targetId) → renderLocation
      ├─ 点击返回按钮 → navigateTo(parentId) → renderLocation
      └─ 点击 NPC 卡片   → openNpcModal(npcId)
          └─ 点击动作按钮 → executeAction(type)
```

## 12. 技术要点

1. **纯 CSS 连线**：伪元素方案代码量小，无需 JS 计算坐标
2. **Grid 布局**：导航按钮自然形成十字形，响应式友好
3. **复用弹窗**：直接套用 lobby.html 的 `.intel-modal-overlay` 样式
4. **复用色彩**：CSS 变量从 lobby.html 原样复制
5. **JSON 单向数据流**：`fetch → 解析 → 渲染`，无框架，纯 vanilla JS
6. **新 HTML 文件**：独立页面，避免与 lobby.html 的 DOM 耦合
