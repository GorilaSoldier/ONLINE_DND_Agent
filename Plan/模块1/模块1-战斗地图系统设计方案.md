## 1. 概述

### 1.1 设计目标

为 DNDBOX 提供**基于地图的战斗交互层**。战斗发生在地图上：玩家通过点击 token、移动、攻击、施法等方式与敌人对抗，摆脱纯文字的战斗描述。

当前版本（本文档）已实现**完整战斗闭环**：

> **地图底图 + 网格 + 角色 token + 移动范围可视化 + 障碍物阻挡 + 攻击/施法/动作 + 回合制 + 敌人 AI + 战斗结束判定**

### 1.2 核心设计理念

| 要素 | 设计 |
|------|------|
| **定位单位** | 格子（正方形网格），token 吸附格子中心 |
| **范围判定** | 圆形（半径 = 米数），**圆只筛选格子，不参与定位** |
| **可达计算** | 扩散算法（水波式），绕开障碍物 |
| **数据单位** | 角色卡存**米**，地图显示**格**，1 格 = 1.5m |
| **交互** | 点击动作按钮 → 自动选中角色 → 显示射程圆+目标高亮 → 点击目标结算 |
| **结算** | 前端本地掷骰引擎（actions.js），D&D 5e 规则，不依赖 AI GM |
| **回合** | 真掷先攻（d20+敏捷），玩家回合 ↔ 敌人回合轮转 |

### 1.3 页面定位

- 文件：`combat-map.html`（独立页面）
- 复用 lobby.html 的色彩体系（CSS 变量）
- 三栏布局：左侧场景上下文 + 中央战斗地图 + 右侧角色卡
- 战斗场景由地图配置 `scene` 字段关联冒险章节（如 `ch1-scene2` 三猪小径）

### 2.1 顶部栏

- 左侧：返回按钮
- 中央：DNDBOX 品牌

### 2.2 中央区域：战斗地图

- **底图**：PNG 图片（如 `三猪小径.png`），按容器比例缩放
- **网格**：覆盖在底图上的正方形网格（`grid_cols × grid_rows`）
- **障碍层**：树/岩石/墙等不可通行格（半透明深色覆盖）
- **高亮层**：可移动/可选目标格（蓝色半透明 + 边框）
- **token 层**：圆形角色 token（玩家蓝 / 敌人红），含 HP 条 + `HP:xx` + `Lv.xx`
- **射程圆**：攻击/法术选择目标时显示（红色虚线，半径=米数换算）
- **飘字层**：伤害（红 `-x`）/ 治疗（绿 `+x`）短暂上浮动画

#### 2.2.1 状态栏

- 显示当前战斗状态（先攻结果 / 当前回合 / 结算播报 / 操作提示）
- **结束回合按钮**：玩家回合可用，点击切到敌人回合
- 图例：玩家 / 敌人 / 可移动格

### 2.3 左侧面板：场景上下文

与文字冒险界面一致，但显示**当前战斗地点的数据**（由地图配置 `scene` 字段切换）：

- **人物**：当前地点的 NPC（如 4 只地精伏击者），点击看详情
- **物品**：当前地点的物品（如 空地图匣、散落的物资）
- **队伍成员 / 当前任务**：从冒险章节加载

### 2.4 右侧面板：角色卡 + 动作面板

完整角色卡（与文字冒险一致），其中**技能&法术 tab 兼作战斗动作面板**：

| 区块 | 内容 | 交互 |
|------|------|------|
| **攻击** | 近战攻击 (+x / 伤害骰)、远程攻击 | 需目标：射程圆 + 敌人高亮 → 点击结算 |
| **常规动作** | 跳跃 / 投掷 / 冲刺 | 跳跃：选落点（无视障碍）；冲刺：移动翻倍；投掷：需目标 |
| **职业动作** | 斗气如潮 / 回复 / 附加攻击 | 自身目标，点击直接生效 |
| **戏法** | 火焰箭（1d10，9米，无限施放） | 需目标 |
| **1 环法术** | 治愈术（触碰） | 需目标 |

> 无需先点角色：点动作按钮自动选中己方 token 并进入对应状态。

## 3. 交互模型

### 3.1 状态机

```
idle ──点击己方token──▶ selected ──点击可达格──▶ moving
  ▲                        │  ▲                     │
  └──────结束回合/取消───────┘  └──动画结束──▶ idle
                          │
                          └──点动作按钮──▶ targeting（选目标）
                                          │  └─点敌人▶ 结算 ──▶ selected
                                          └─点「跳跃」──▶ jumping（选落点）
                                                             └─点空地▶ 跳跃移动
```

| 状态 | 触发 | 行为 |
|------|------|------|
| `idle` | 未选中 | 点己方 token 进入 selected |
| `selected` | 选中 | 显示移动范围（蓝格），可点动作按钮 |
| `moving` | 点击可达格 | 平滑移动，期间禁止操作 |
| `targeting` | 点攻击/法术 | 射程圆 + 射程内敌人红圈高亮，点敌人结算 |
| `jumping` | 点跳跃 | 跳跃范围蓝格高亮，点落点飞跳（无视障碍） |

### 3.2 回合轮转

```
战斗开始 → 掷先攻（d20+敏捷）→ 先手方行动
    [玩家回合] 自由移动/攻击/施法/动作 → 点「结束回合」
    → [敌人回合] 存活地精逐只 AI 行动（间隔 700ms）
    → 回到 [玩家回合] ... 循环直到战斗结束
```

- 非玩家回合（`enemy`）禁止一切玩家操作（地图点击 / 动作按钮均拦截）
- 玩家死亡 → 战斗失败；敌人全灭 → 战斗胜利（地图中央横幅提示）

## 4. 单位体系：米 ↔ 格

### 4.1 换算桥

```
1 格 = 1.5 米（D&D 5e 标准：1 格 = 5 英尺 ≈ 1.5m）
```

地图配置文件声明比例尺，前端启动时换算：

```json
{
  "meters_per_cell": 1.5,
  "grid_cols": 18,
  "grid_rows": 24
}
```

### 4.2 换算示例

| 角色卡数据（米） | 换算 | 用途 |
|---|---|---|
| `move_speed: "4.5m"` | 4.5 ÷ 1.5 = 3 格 | 扩散步数（elias） |
| `melee_range: "1.5m"` | 1.5 ÷ 1.5 = 1 格 | 近战距离 |
| `ranged_range: "6m"` | 6 ÷ 1.5 = 4 格 | 远程射程 |
| 法术 `range: "9米"` | 9 ÷ 1.5 = 6 格 | 火焰箭/火球术射程 |

> 说明：BG3 中火焰箭/火球术为 18 米（12 格）。因战斗地图仅 18×24 格，射程 12 格几乎覆盖全图，已压缩到 9 米（6 格）保证比例协调。

## 5. 地图与网格

### 5.1 地图配置数据结构（`data/combat/maps/<map_id>.json`）

```jsonc
{
  "id": "triboar-trail-ambush",
  "name": "三猪小径·伏击点",
  "image": "/pic/地图/三猪小径.png",
  "scene": "ch1-scene2",            // 关联冒险章节场景，驱动左侧面板数据
  "meters_per_cell": 1.5,
  "grid_cols": 18,
  "grid_rows": 24,
  "obstacles": [
    { "col": 6, "row": 10, "kind": "wall" },   // tree / rock / wall
    { "col": 7, "row": 11, "kind": "wall" }
  ],
  "spawns": {
    "players": [{ "col": 2, "row": 12 }],
    "enemies": [{ "col": 14, "row": 9 }, { "col": 15, "row": 11 }]
  }
}
```

### 5.2 障碍物（不可通行格子）

- 障碍类型：`tree`（树）/ `rock`（岩石）/ `wall`（墙）
- 全部进入 `obstacleSet`（`"col,row"` key），用于移动扩散断开 + 跳跃落点校验
- 窄墙可绕行；封死路的墙使其后方格子天然不可达（由扩散保证）

### 5.3 障碍物渲染

- 每个障碍格渲染半透明深色覆盖层，直接覆盖底图对应格子

## 6. Token 设计

### 6.1 外观

- 圆形，直径约 0.8 格，圆心显示角色名首字（玩家「埃」/ 敌人「地」）
- 阵营配色：玩家蓝色、敌人红色（复用 FACTION_STYLES）
- **HP 条**：圆形下方横条，按 HP 比例变色（绿 → 黄 → 红）
- **HP 数字**：右上角 `HP:xx`
- **Lv 徽章**：左上角 `Lv.x`（玩家从角色 level 读取，敌人默认 1）

### 6.2 定位

- token 吸附格子中心，移动时沿格子路径平滑滑动（CSS transition）
- **命中区**：至少 48px 方形（小地图保证易点中）；跳跃选落点期间临时置为 `pointer-events:none` 防吞点击

### 6.3 状态

| 状态 | 表现 |
|---|---|
| 空闲 | 正常显示 |
| 选中 | 白色高亮描边 + 蓝色移动范围 |
| 可攻击目标 | 红圈高亮（射程内敌人） |
| 死亡 | 半透明（opacity 0.35） |

## 7. 移动与跳跃

### 7.1 移动交互流程

```
点动作/点击己方 token → 计算移动范围（圆筛选 ∩ 扩散可达）
    → 蓝色高亮可选格 → 点击目标格 → 沿路径平滑移动 → 恢复状态
```

- 移动范围 = 移动半径圆内（格子中心距离 ≤ move_speed 米）∩ 扩散可达（走得过去）
- 可移动格点击后走最短路径（回溯步数表）

### 7.2 跳跃（跨障碍）

D&D 5e 远跳规则：跳跃距离 = **力量值 英尺**（每格 5 英尺）。

```
jumpRangeCells = round(力量值 / 5)     // elias 力量17 → 3 格
```

- 点「跳跃」→ 蓝色高亮跳跃落点范围（半径 3 格，排除障碍格）
- 点落点 → token 飞跳过去，**路径无视障碍**（可跳越墙/树/岩石）
- 落点校验：不能是障碍格 / 不能是其他生物占据格
- 高度系统（登高/跳高台）待后续实现

## 8. 战斗系统

### 8.1 回合制

| 环节 | 实现 |
|------|------|
| **先攻** | 真掷骰：`d20 + 敏捷调整值`，玩家 vs 地精群体最高值；玩家先手或地精先手随机 |
| **玩家回合** | 不限移动/动作次数，点「结束回合」按钮切到敌人回合 |
| **敌人回合** | 存活地精逐只行动，间隔 700ms，结束后自动回到玩家回合 |
| **回合锁定** | `combatPhase`（idle/player/enemy/victory/defeat），非 player 回合禁止操作 |

### 8.2 结算引擎（`js/combat/actions.js`，前端本地掷骰）

| 结算 | 规则 |
|------|------|
| **普攻** | `d20 + 攻击加值` vs 目标 AC；命中掷伤害骰；重击(20)伤害翻倍；1 自动失手 |
| **法术** | 解析 `effect` 字段：`damage NdM 类型` / `heal NdM+mod` / `narrative`；带豁免的目标豁免判定 |
| **自身动作** | 回气（1d10+等级）/ 回复（1/4 最大 HP）/ 冲刺（移动翻倍）/ 斗气如潮 |
| **骰子** | 兼容骰子格式（`1d8+3`）与旧范围格式（`6~16`） |

### 8.3 玩家攻击/施法

```
点右侧动作按钮 → 自动选中己方 token → targeting 状态
    → 射程圆（攻击：近战1格/远程4格；法术：range 字段）
    → 射程内敌人红色高亮 → 点击敌人 → resolveAttack/resolveSpell 结算
    → 敌人 token 飘红字 + HP 扣减 → 右侧角色卡 HP 同步
```

### 8.4 敌人 AI（地精）

| 距离（格） | 行为 |
|---|---|
| ≤ 1（近战） | **弯刀**近战（+4 / 1d6+2） |
| ≤ 4（远程） | **短弓**远程（+4 / 1d6+2） |
| > 4 | 向玩家靠近（可达范围内选离玩家最近的格子移动） |

- 攻击复用 `resolveAttack`，伤害扣到玩家 token，飘红字 + 右侧角色卡同步
- 敌人数据来自 `npcs.json` 的 `combat` 字段（ac / hp / move_speed / attacks）

### 8.5 战斗结束

- 玩家击杀最后一只敌人 → **胜利**（绿色横幅「⚔ 战斗胜利」）
- 玩家 HP ≤ 0 → **失败**（红色横幅「☠ 战斗失败」，token 变灰）
- 结束后禁止继续操作

## 9. 数据流

```
combat-map.html 加载
    │
    ├─ 读取地图配置 data/combat/maps/<map_id>.json（障碍、出生点、scene）
    │
    ├─ 读取冒险章节数据（scene → npcs/items/quests → 左侧面板）
    │
    ├─ 读取角色卡 characters/elias.json → 重算攻击/AC → 玩家 token
    │
    ├─ 读取 npcs.json combat → 敌人 token（HP/AC/attacks）
    │
    ├─ 读取 spells.json → 法术查找表（动作面板 + 结算）
    │
    └─ 玩家交互
        ├─ 点动作按钮 → targeting → 点目标 → actions.js 结算
        ├─ 点「结束回合」→ 敌人 AI 回合 → 结算回玩家
        └─ 战斗结束 → 横幅 + 锁定操作
```

## 12. 设计决策记录

| 决策 | 原因 |
|------|------|
| 圆 + 方格不冲突，圆只筛选格子 | 圆是"判定圈"，格是"落脚点"，token 永远吸附格中心 |
| 四方向扩散，墙后格子天然不可达 | 水波在墙边断开，源头杜绝"看着近走不过去" |
| 结算引擎放前端本地（actions.js） | 战斗地图不依赖 AI GM；后端只在持久化/AI 叙事时才介入 |
| 普攻/法术/敌人 AI 复用同一 resolveAttack | 一套骰子规则，玩家与敌人对等，无需两套逻辑 |
| 法术射程 18 米 → 9 米 | BG3 原版 18 米 = 12 格，覆盖 18×24 图大半；9 米（6 格）比例协调 |
| 战士配火焰箭戏法（1d10）而非火球术（8d6） | elias 是 4 级战士，火球术是法师 3 环 AoE，战士不该有；火焰箭符合"战士魔法攻击"定位 |
| 跳跃距离 = 力量值/5（round） | D&D 5e 远跳规则（力量17 → 3 格），不超 RAW 上限 |
| 跳跃无视路径障碍，只校验落点 | 跳越墙/树是跳跃的核心价值；高度判定留到 M7 |
| 跳跃期间 token 置 pointer-events:none | token 命中区 48px 会吞掉落点点击（玩家在 (9,12) 点 (9,10) 被当成点自己） |
| 真掷先攻（d20+敏捷） | 符合 D&D 规则；地精(+2) 略优，开场有紧张感 |
| 玩家回合不限动作次数 | 第一版简化，避免资源管理复杂度；回合制跑通后再评估 |
| 敌人攻击也走 onResolve 同步 HP | 玩家回合/敌人回合共用同一回调，右侧角色卡始终与地图一致 |
| 敌人数据进 npcs.json combat 字段 | NPC 模板自带战斗数据，新遭遇只需引用 npc id |
